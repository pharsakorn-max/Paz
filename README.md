# ไพ่ทาโรต์ 78 ใบ (PWA สำหรับ iPhone)

เว็บแอปดูดวงไพ่ทาโรต์ Rider–Waite ครบ 78 ใบ (Major Arcana 22 + Minor Arcana 56) มีความหมายภาษาไทยทั้งแบบตั้งตรง (upright) และกลับหัว (reversed)

## ความสามารถ
- รูปแบบการวางไพ่: 1 ใบ, 3 ใบ (อดีต / ปัจจุบัน / อนาคต), Celtic Cross 10 ใบ
- เปิด/ปิดไพ่กลับหัวได้ (โอกาสกลับหัว 50%)
- สุ่มด้วย `crypto.getRandomValues` และ Fisher–Yates shuffle (ไม่ใช้ `Math.random`)
- เลือกหมวดคำถาม (ความรัก / การงาน-การเรียน / การเงิน / สุขภาพ / ทั่วไป) หรือให้ตรวจจากคำถามอัตโนมัติ
- ตีความในเครื่อง (offline): ความหมายตามหมวด ตำแหน่ง เลข ไพ่บุคคล ธาตุเสริม/ขัด (elemental dignities) เส้นเรื่อง อดีต→อนาคต และแนวโน้มคำตอบใช่/ไม่
- ตรวจความกำกวม แล้วเปิดไพ่ขยาย (clarifier) ได้สูงสุด 3 ใบต่อตำแหน่ง ไพ่ขยายถูกนำไปคำนวณน้ำหนักคำตอบใหม่
- ตีความเชิงลึกด้วย Claude (เฉพาะเมื่อเปิดผ่าน claude.ai artifact) ตามคำถามจริง พร้อมแนะนำตำแหน่งที่ควรเปิดไพ่ขยาย
- คัดลอกคำทำนายไปวางใน LINE หรือโน้ตได้
- ประวัติ 30 ครั้งล่าสุด เก็บใน `localStorage` ของเครื่อง
- ใช้แบบ offline ได้ผ่าน service worker หลังเปิดครั้งแรก

## สำรับเทพฮินดู (Hindu God Tarot)
- เลือก "สำรับเทพฮินดู" ในแอป หรือเปิดด้วย `#hindu` ท้ายลิงก์
- ไพ่ 78 ใบจับคู่กับเทพหรือตำนานฮินดู (รามายณะ มหาภารตะ ปุราณะ) พร้อมคำบรรยายตำนานของแต่ละใบ
- ชุดไพ่ตามธาตุ: อัคนี (ไฟ, Wands), วรุณ (น้ำ, Cups), วายุ (ลม, Swords), ปฤถวี (ดิน, Pentacles)
- รูปเทพตั้งตรงเสมอ ไพ่กลับหัวแสดงด้วยกรอบและแถบสีแดงแทนการหมุนภาพ
- หน้าไพ่เป็นสัญลักษณ์ลายเส้น (อาวุธ พาหนะ เครื่องบูชา) และชื่อเทวนาครี ไม่ใช่ภาพวาดเทพ

## ไพ่ออราเคิลเทพฮินดู (`oracle.html`)
- 44 ใบ: เทพ เทวี อวตาร นพเคราะห์ และฤๅษี แต่ละใบมีสาส์น สิ่งที่ควรทำ ข้อควรระวัง และบทสวดนมัสการ (เทวนาครี/ทมิฬ พร้อมคำอ่านไทย)
- ไม่อิงความหมายไพ่ทาโรต์ และไม่มีไพ่กลับหัว
- วางไพ่ได้ 3 แบบ: 1 ใบ (สาส์นจากเทพ), 3 ใบ (เป็นอยู่ / ควรทำ / คลี่คลาย), 5 ใบ (ปัญจภูต ห้าธาตุ)
- ขอสาส์นเพิ่มได้ตำแหน่งละ 2 ใบ และอ่านเชิงลึกด้วย Claude เมื่อเปิดผ่าน claude.ai

## ติดตั้งบน iPhone
1. host ไฟล์ทั้งหมดบน HTTPS เช่น GitHub Pages, Netlify หรือ Cloudflare Pages
2. เปิดลิงก์ใน **Safari** แล้วกด Share → **Add to Home Screen**

## ข้อจำกัด
- ไม่ใช่ native app และไม่อยู่ใน App Store
- หน้าไพ่เป็นสัญลักษณ์ชุดไพ่ ไม่ใช่ภาพวาด Rider–Waite ต้นฉบับ
- การตีความในเครื่องเป็นแบบกฎ (rule-based) อ่านความหมายของคำถามไม่ได้ ใช้แค่คำสำคัญเพื่อเลือกหมวด
- การตีความด้วย Claude ใช้ไม่ได้ในเวอร์ชัน PWA ที่ host เอง และใช้ปริมาณการใช้งานของบัญชี Claude ผู้เปิด
- ประวัติหายถ้าลบข้อมูล Safari หรือ iOS ล้าง storage ของเว็บแอปที่ไม่ได้เปิดนาน
